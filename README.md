# Korean by Svetlana — Telegram Mini App

A lightweight Telegram Mini App landing page for Korean teacher Svetlana.

## Screens
- About me
- Lessons
- Booking
- Telegram channel

## Deployment
The app is a static site and can be deployed with GitHub Pages. After Pages is enabled for the `main` branch root, the app will be available at:

`https://lana142.github.io/korean-by-svetlana-miniapp/`

## Before launch
Replace the placeholder Telegram links in `app.js` with the real channel and personal username. Add `assets/svetlana.jpeg` (the supplied portrait) to the repository if you want the portrait displayed.
